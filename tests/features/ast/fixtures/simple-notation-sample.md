# 1. 行頭インライン・マーカー

__この行は __ で字下げされています。
　＿全角の ＿ でも字下げできるはずです。

_
1行あけ（L-8）
_3
3行あけ（L-8）

|| 中央寄せの段落（Simple形: R-C）
|> 右寄せ（end）の段落（Simple形: R-C）
<| これも end に正規化される typo 寛容記法

# 2. 文字装飾（Simple形）

__本文中で ==重要== をハイライト。
__色付きは ==[red]赤== や ==[#fde68a]hex== で指定。
__圏点は ^^強調したい文字^^ に付与。
__ルビは [[ruby:漢字|かんじ]] と書きます。

__自由度の高い装飾：
- :太字で赤:bold,red:
- :大きく背景黄:lg,bg-yellow:
- :1.5emサイズ:1.5em:
