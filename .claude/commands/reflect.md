`knowledge-reflection` スキルの手順で、このセッションの知見を `.claude` へ反映する。

> user の合図(2026-07-26 確立):
> 「**着地後に知見を .claude に反映してくれ**」
> ── この言い回し自体がトリガー。`/reflect` はその明示版。

## 進め方

1. **着地を確認**する(`git fetch --prune origin main` → merge 済みか)。
   未着地なら「まだ着地していない」と伝えて、着地を待つか強行するか確認する
2. スキル §1 の **4 種類**(踏んだ罠 / 覆った前提 / user 裁定 / 実態との乖離)だけ拾う
3. スキル §2 の表で **書き先**を決める(迷ったら既存スキルへ足す。新設は最後の手段)
4. スキル §3 の型で書く
   - 罠は「症状 → 原因 → 規律」。**機械的に判定できる形**にする
   - 覆った前提は **古い見立ても残す**(消すと同じ判断が繰り返される)
   - user 裁定は `(user 指示/裁定 YYYY-MM-DD)` の出典タグ付き = 不可侵
5. **反映だけの PR** として出す(実装と混ぜない)
6. スキル §5 の自己点検を通す

引数があれば、反映する対象を絞る(例: `/reflect perf` → 計測まわりだけ)。
